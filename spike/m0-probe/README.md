# M0 探针

[M0 技术验证](../../docs/plan.md#m0技术验证)用的最小扩展。它在知乎页面上只读地记录结构信息，提供几个可以开关的实验，并把结果汇总成一份可以导出的报告。报告的每一部分对应计划里 M0 的一项。

## 会做什么，不会做什么

- **只记录**：字段名和类型、数量、`type` / `verb` / `kind` 这类枚举值、计时、页面报错次数。
- **不记录**：正文、标题、用户名、内容 id、Cookie、请求头的值。接口地址里的数字和用户标识会被替换成 `:id`、`:token`。
- **不联网**：扩展本身不发起任何网络请求，数据只保存在本机（`chrome.storage.local`）。
- **实验默认关闭**：打开后只改变你自己浏览器里的页面显示，不会对知乎做任何写操作。

## 安装（Chrome / Edge）

1. 获取代码：克隆仓库并切到 `claude/optimistic-lovelace-hr7yjp` 分支，或在 GitHub 上下载该分支的 ZIP。
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开"开发者模式"。
3. 点"加载已解压的扩展程序"，选择 `spike/m0-probe/extension` 文件夹。
4. 点探针的"详细信息"，打开"允许用户脚本"（Chrome 138 起才有这个开关；更早的版本打开开发者模式即可）。如果 Edge 上找不到这个开关，请记下来，这本身就是 M0 要确认的结论。
5. 点工具栏里的探针图标 →"重新检测用户脚本"，显示"可用"即可。

请在平时使用、已经登录知乎的浏览器里安装，这样测到的才是真实情况。

## 更新探针

1. 在仓库目录执行 `git pull`。
2. 在 `chrome://extensions` 的"M0 探针"卡片上点刷新按钮，再刷新已经打开的知乎页面。
3. 要重新测试时，先在报告页点"清空数据"，避免新旧结果混在一起。

版本号显示在 `chrome://extensions` 的卡片上，当前是 0.1.2。

## 测试步骤（大约 20 分钟）

### 第一轮：不开实验，正常浏览

尽量用**站内点击**跳转，不要都在地址栏直接输入网址，这样才能测到单页应用的路由变化。

1. 首页推荐：往下滚动加载两三页；再切到"关注"和"热榜"。
2. 点开一个问题：往下滚动加载更多回答，展开一个评论区。
3. 从问题页点进一个单独的回答，再用浏览器"后退"。
4. 打开一篇专栏文章（`zhuanlan.zhihu.com`）。
5. 搜索一个关键词，往下滚动一点。
6. 打开任意一个用户主页。
7. 在问题页上，点探针弹窗里的"测试知乎自带暗色"，看页面是否整体变暗（3 秒后恢复）。

### 第二轮：逐项实验

每次只开一项，在弹窗里修改后**刷新页面**（专栏文章所在的 `zhuanlan.zhihu.com` 请刷新两次），测完改回"关闭"。

| 实验 | 怎么做 | 看什么 |
|---|---|---|
| 接口数据过滤：去掉一半条目 | 刷新首页，往下滚动 | 页面是否正常，新加载的条目是否变少 |
| 接口数据过滤：去掉全部条目 | 刷新首页和问题页，往下滚动 | 还能不能继续加载，页面会不会卡住 |
| 首屏数据改写：原样写回 | 刷新首页和问题页 | 页面是否一切正常 |
| 首屏数据改写：删掉一个回答的数据 | 刷新一个问题页 | 页面是否报错、白屏 |
| 首屏预隐藏 | 刷新首页和问题页几次 | 首屏有没有闪烁，或者空白时间过长 |

首屏的内容来自页面自带的数据，接口过滤只影响之后加载的内容，所以要往下滚动才能看到效果。

### 最后

1. 在弹窗里点"打开报告"。
2. 在报告最下方的"人工观察"里填写看到的情况，点"保存"。
3. 点"下载 JSON"，把文件发给我。发送前可以自己打开检查一遍。

## Firefox（可选）

1. 复制一份 `extension` 文件夹，把其中的 `manifest.firefox.json` 改名为 `manifest.json`（覆盖原文件）。
2. 打开 `about:debugging#/runtime/this-firefox` →"临时载入附加组件"，选择这个 `manifest.json`。
3. 在扩展管理里允许它访问 `zhihu.com`（Firefox 默认不自动授予网站权限），再在弹窗里点"授予用户脚本权限"。

Firefox 版本没有在这里测试过。如果装不上或者报错，把错误信息发给我，这也是 M0 的结论之一。

## 开发者：冒烟测试

`dev/` 下有一个模拟的知乎页面和冒烟测试。它用 Playwright 启动带扩展的 Chromium，把 `*.zhihu.com` 指向本地服务器（带严格的 CSP），检查每项探测都能产生记录、报告里没有用户标识、报告页能正常渲染。

```
cd spike/m0-probe/dev
npm install
npx playwright install chromium   # 首次运行需要
npm run smoke
```

冒烟测试只能证明探针本身能工作；知乎真实页面上的结论，还要靠上面的手动测试。
