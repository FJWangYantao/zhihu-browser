# zhihu-browser（暂名）

开源的知乎浏览增强扩展，支持 Chrome、Edge 和 Firefox。

- **核心小而稳定**：知乎改版时只需修复适配层，插件不受影响。
- **一切皆插件**：屏蔽、主题、阅读模式、快捷键都是插件，内置功能和第三方插件用同一套 API。
- **人人能写插件**：从零代码配置，到单文件插件，再到完整插件包；API 足够小，AI 读完文档就能写。
- **安全可信**：开源、最小权限、零遥测，不接触账号密码。

设计理念参考了 [pi](https://github.com/badlogic/pi-mono) 的"小核心 + 可扩展"。

> 当前进度：M1 已完成；M2（用户插件和 Firefox）主体已完成，还有几项没有实测，见[项目计划](docs/plan.md#m2用户插件和-firefox)。七个官方插件（屏蔽、主题、信息增强、键盘浏览、阅读模式、高清原图、去干扰）都可以试用，也可以自己写插件，见下面的"试用"和"写插件"。

## 试用

1. 按下面"开发"一节构建扩展，或者在 GitHub Actions 的运行记录里下载 CI 构建好的扩展（`zhihu-browser-chrome-mv3`）并解压。
2. 在 Chrome 或 Edge 里打开 `chrome://extensions`，打开右上角的"开发者模式"，点"加载已解压的扩展程序"，选择 `apps/extension/.output/chrome-mv3` 目录（或解压出来的目录）。
3. 打开知乎。点浏览器工具栏里的扩展图标，进入设置页。

官方插件：

- **屏蔽**：按关键词（支持 `/正则/`）、作者、内容类型（视频、想法、付费内容）屏蔽，默认去掉广告和推广；可以折叠并显示原因，也可以直接去掉；内容下方有"屏蔽作者"按钮；评论也按关键词和作者屏蔽。
- **主题**：浅色、暗色或跟随系统（用知乎自带的暗色，补上导航栏、评论区等没跟着变暗的地方）；正文字体、字号、行高；主栏宽度（宽屏）；隐藏右侧栏。默认全部跟随知乎，不改变页面。
- **信息增强**：在内容标题旁显示完整的发布时间、编辑时间和字数。
- **键盘浏览**：j / k 切换内容，o 展开全文，c 收起，Shift+C 收起全部，g g 回到顶部；这些操作在命令面板里也能找到。
- **阅读模式**：在回答、文章页按 r，全屏显示标题、作者和清理过的正文；字号、宽度、字体、配色可调，Esc 关闭。
- **高清原图**：正文里的图片换成原图，点击用大图查看器看（← → 切换，点击放大到原始尺寸）。
- **去干扰**：隐藏横幅广告、推广卡片、创作者中心入口，并在渲染之前去掉信息流里的广告和推广；可以自己加要隐藏的元素。

修改设置后，已经打开的知乎页面立即生效，不用刷新。在设置页关掉插件，或者打开安全模式，页面就和没装扩展时一样。

在知乎页面上按 Ctrl+K（macOS 上是 ⌘K）打开命令面板，可以查看快捷键、查看插件状态与日志、打开设置页。有功能没生效时，在命令面板里运行"页面结构诊断"，把结果复制给开发者（只有标签名、类名和尺寸，不含文字和账号信息）。知乎改版之后，可以用"采集页面样本"导出一份脱敏的页面（文字换成占位符，id 换成编号，不含图片和账号信息），作为适配层的回归测试，见 [页面样本](docs/fixtures.md)。设置页里可以改快捷键，也可以把插件设置导出成数据包分享给别人，或者导入别人的数据包（导入前会先列出要改动的设置）。

扩展不收集任何数据，设置只保存在本机浏览器里；不主动请求知乎的接口，也不会替你在知乎上做任何操作。

## 写插件

用户插件是一个 `.ts` 或 `.js` 文件，在设置页的"安装用户插件"里粘贴、选择文件或从链接安装；安装之前会先显示权限和完整源码，确认之后才运行。需要先在浏览器里允许扩展运行用户脚本（Chrome 138+ / Edge 在扩展详情页打开"允许用户脚本"；Firefox 在设置页授予权限），设置页上有引导。

- 零基础：把 [给 AI 的指南](docs/ai-guide.md) 和你的需求一起交给任意 AI，把它写出的文件装进去。
- 写代码：用 [插件项目模板](templates/plugin)（TypeScript + 类型提示，打包成单文件）；`pnpm dev` 之后在设置页点"开发模式：监听更新"，保存即热重载。
- 参考：[插件 API](docs/plugin-api.md)、[示例](docs/examples/)、官方插件的源码（`plugins/` 下的每一个都可以原样作为用户插件安装）。

## 开发

需要 Node.js 22.12 以上和 pnpm（执行 `corepack enable` 即可使用仓库指定的 pnpm 版本）。

```
pnpm install
pnpm build       # 构建扩展，输出在 apps/extension/.output/chrome-mv3
pnpm build:firefox  # 构建 Firefox 版（需要 Firefox 136+），输出在 apps/extension/.output/firefox-mv3
pnpm lint        # 代码规范（Biome）
pnpm typecheck   # 类型检查，包括 docs/plugin-api.md 里的示例
pnpm test        # 单元测试（Vitest）
pnpm e2e         # 端到端测试：在本地模拟的知乎上用 Chromium 加载构建好的扩展，包括用户插件（先执行 pnpm build）
```

构建好的扩展可以在 `chrome://extensions` 里用"加载已解压的扩展程序"加载。CI 每次构建后也会上传扩展，可以在 GitHub Actions 的运行记录里下载。

| 目录 | 内容 |
|---|---|
| `apps/extension` | 浏览器扩展（WXT） |
| `packages/sdk` | 插件 API 的类型定义 |
| `packages/core` | 插件宿主：生命周期、钩子调度、隔离与熔断、设置、存储、权限 |
| `packages/adapter-zhihu` | 知乎适配层：接口拦截、数据整理、页面元素识别、内容上的界面工具、页面样本采集。知乎改版只修这里；`test/pages/` 是页面样本 |
| `packages/ui` | 核心界面：提示、确认框、挂载点、命令面板、快捷键与插件状态面板、键盘分发 |
| `plugins/filter` | 官方插件"屏蔽" |
| `plugins/theme` | 官方插件"主题"：只设置主题 token，由适配层映射到知乎页面 |
| `plugins/info` | 官方插件"信息增强" |
| `plugins/shortcuts` | 官方插件"键盘浏览" |
| `plugins/reader` | 官方插件"阅读模式" |
| `plugins/hd-images` | 官方插件"高清原图" |
| `plugins/declutter` | 官方插件"去干扰" |
| `packages/remote` | 用户插件的跨环境运行：用户脚本环境里的 SDK 运行时，和扩展隔离环境里把它接到宿主上的代理 |
| `packages/installer` | 用户插件的安装器：转译 TS / ESM、不执行代码就解析 meta、比较权限 |
| `templates/plugin` | 插件项目模板 |
| `docs/examples` | 示例插件（嵌进了给 AI 的指南，CI 里类型检查并经过安装器解析） |
| `spike/m0-probe` | M0 技术验证用的探针扩展 |
